Self-hosted fonts, subset to Latin with fontTools (WOFF):

- `dm-sans-latin-var.woff` — DM Sans variable (opsz, wght) from https://github.com/googlefonts/dm-fonts
- `dm-mono-latin-regular.woff`, `dm-mono-latin-medium.woff` — DM Mono from https://github.com/googlefonts/dm-mono
